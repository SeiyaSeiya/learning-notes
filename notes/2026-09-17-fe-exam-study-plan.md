# 基本情報技術者試験（FE）の学習方法・出題範囲・学習計画

- 学んだきっかけ: 隙間時間（平日昼休み20分＋週末）で基本情報技術者試験の勉強をしたいと思い、Claudeに学習サイトのおすすめ、直近の試験日程、出題範囲、学習計画の相談をした際のメモ。学習計画そのものはClaudeのアーティファクト（Docs）としても作成し、[fe-exam-study-plan.html](2026-09-17-fe-exam-study-plan.html) に書き出してある（元は編集可能なドキュメントとしてアプリ上で随時更新する運用）。

## 1. 学習リソース（無料中心）

- **過去問道場（fe-siken.com）**: 無料の会員登録だけで、科目A・科目Bどちらも過去問をランダム演習でき、正誤判定と解説がその場で出る。1問1〜2分程度なので、昼休み20分あれば10問前後＋解説読み込みが収まる。広告非表示や成績分析などの有料プラン（プレミアム会員）もあるが、演習自体は無料範囲で十分。
- **IPA公式の科目Bサンプル問題（PDF）**: 新試験制度（疑似言語のアルゴリズム問題）に慣れる練習として質が高く、完全無料。
- **paizaラーニング / Progate**: 科目Bのアルゴリズム対策の補助になるが、無料で使える範囲は限定的（基礎レッスンのみ等）。
- **YouTube解説動画**（例: すーさんの合格チャンネル等）: イヤホンが使える環境向け。科目Bのアルゴリズム解法などが短い動画に区切られていて聞き流しやすい。

## 2. 試験日程（2026年9月17日時点、IPA公式情報）

- 現行の基本情報技術者試験はCBT方式で通年随時実施。ただし2026年9月1日以降の申込みは「申込日〜2026年12月27日」の範囲でしか受験日を選べない制限がかかっている。
- 2026年12月28日以降、CBT試験はシステムメンテナンスのため一時休止予定（会場によってはそれより早く休止する場合あり）。次回受付時期は本記事時点で未発表。
- 現行の試験制度自体は2026年度で終了し、2027年度春頃から新制度に移行予定。ただしIPAの告知によれば「問う知識・技能の範囲そのものに変更はない」用語整理レベルの改定とのことで、2026年内受験なら現行の出題範囲がそのまま当てはまる。
- 申込み窓口: [cbt-s.comの受験者ポータル](https://cbt-s.com/examinee/examination/fe)。

## 3. 試験の構成と出題範囲

| | 科目A | 科目B |
| --- | --- | --- |
| 試験時間 | 90分 | 100分 |
| 問題数 | 60問 | 20問 |
| 出題形式 | 四肢択一 | 多肢選択 |
| 合格ライン | 600点/1000点 | 600点/1000点 |

- 科目Aの出題範囲: テクノロジ系（約7割）／マネジメント系（約1割）／ストラテジ系（約2割）。
- 科目Bの出題範囲: プログラミング（擬似言語によるアルゴリズム・データ構造の読解力を問う問題、約8割＝16問）／情報セキュリティ（約2割＝4問）。
- 科目Bは全問が技術系の問題のため、試験全体で見ると「テクノロジ系＋科目B」で技術系の比重は科目Aの数字（7割）以上に大きい、というのが実態。

## 4. 学習の優先順位（自分の場合）

IT実務経験はあるが試験勉強は初めて、という前提での優先順位:

1. 科目Bのアルゴリズム（配点が大きく、伸びるまで一番時間がかかる）
2. 科目Aのテクノロジ系のうち苦手な分野
3. マネジメント系・ストラテジ系（過去問道場で数回流す程度で十分。用語暗記型の問題が多く投下時間へのリターンが早い分野でもある）

## 5. 学習計画（4フェーズ、詳細はアーティファクト参照）

- 目標受験時期: 2026年12月27日までのCBT。推奨受験日は12月6日頃〜中旬、遅くとも12月20日頃までを予備日として確保。会場予約はフェーズ3開始（11月5日頃）までに済ませておく（人気会場・希望日時は早めに埋まるため）。
- 使える学習時間: 平日昼休み20分（週5回で約100分/週）＋週末にまとまった時間。
- フェーズ構成:
  1. 全体把握（9/17〜10/7）: 過去問道場で科目Aをランダム演習し、出題傾向と自分の苦手分野をつかむ。
  2. 基礎固め（10/8〜11/4）: 科目Bのアルゴリズムを最優先で演習しつつ、科目Aの苦手なテクノロジ系分野を演習。
  3. 科目B強化（11/5〜11/25）: 科目Bのアルゴリズムを最優先に過去問道場で演習、情報セキュリティも対策。科目Aは復習のみ。
  4. 仕上げ（11/26〜12/6）: 時間を計った通し演習で本番感覚をつかむ。
