# grep・awk・パイプを使ったコマンド出力の検索と抽出

## 概要

GitHub CLI（`gh`）でリポジトリ一覧を取得し、特定の文字列を含むリポジトリ名だけを抽出する方法を調べる中で学んだことを整理する。

主に `grep` と `awk` の役割の違い、パイプによるコマンドの連結、`awk` による列単位のデータ抽出についてまとめる。

## 1. パイプ（`|`）の役割

パイプは、あるコマンドの標準出力を次のコマンドの標準入力に渡す仕組み。

これにより、複数のコマンドを組み合わせてデータを加工できる。

```bash
コマンドA | コマンドB | コマンドC
```

例えば、以下のコマンドでは `gh repo list` の実行結果を `awk` に渡している。

```bash
gh repo list | awk '/new/ {print $1}'
```

## 2. grepコマンド

`grep` は、指定した文字列や正規表現に一致する行を検索・抽出するコマンド。

```bash
grep "new"
```

`new` を含む行が抽出される。

### マッチした部分だけを出力する

`-o` オプションを指定すると、行全体ではなくマッチした部分だけを出力できる。

```bash
grep -o "new"
```

単語単位で `new` を含む文字列を抽出したい場合は、正規表現と組み合わせる。

```bash
grep -oE '[^[:space:]]*new[^[:space:]]*'
```

## 3. awkコマンド

`awk` は、テキストデータを行・列単位で処理するためのコマンド。

デフォルトではスペースやタブなどの空白文字を区切り文字として扱う。

### 特定の列を取得する

```bash
awk '{print $1}'
```

各行の1列目だけを出力する。

主な組み込み変数は以下のとおり。

| 変数 | 役割 |
|---|---|
| `$1` | 1列目 |
| `$2` | 2列目 |
| `$NF` | 最終列 |
| `NF` | 列数 |
| `NR` | 現在の行番号 |

### 条件に一致する行から列を取得する

```bash
awk '/new/ {print $1}'
```

- `/new/`：`new` を含む行を対象にする
- `{print $1}`：該当行の1列目を出力する

### 特定の単語だけを抽出する

行全体ではなく、各列を個別に検索したい場合は以下のようにする。

```bash
awk '{for(i=1;i<=NF;i++) if($i ~ /new/) print $i}'
```

各列を順番に確認し、`new` を含む列だけを出力する。

## 4. grepとawkの使い分け

| コマンド | 主な役割 |
|---|---|
| `grep` | 条件に一致する行を検索・抽出 |
| `awk` | 行・列単位で検索・加工・抽出 |
| `sed` | テキストの置換・削除・編集 |

今回のように、特定の行を検索してから列を取り出す場合は `awk` だけでも実現できる。

## 5. 実践例：GitHubリポジトリ名の抽出

今回の学習のきっかけとなったコマンド。

```bash
gh repo list | awk '/new/ {print $1}'
```

処理の流れ：

1. `gh repo list` でGitHubリポジトリの一覧を取得する。
2. `awk '/new/'` で `new` を含む行を検索する。
3. `{print $1}` で該当行の1列目（リポジトリ名）だけを出力する。

このケースでは、リポジトリ名が1列目にあるため、シンプルな記述で目的を達成できた。

## まとめ

- `|` を使うと、あるコマンドの出力を別のコマンドに渡せる。
- `grep` は主に行単位での検索に使う。
- `grep -o` はマッチした部分だけを出力できる。
- `awk` は行・列単位での検索やデータ加工に便利。
- `awk` はデフォルトで空白文字を区切りとして扱う。
- `awk '/条件/ {print $1}'` のように、条件に一致する行から特定の列だけを抽出できる。

コマンドの実行結果を加工する際は、目的に応じて `grep` と `awk` を使い分ける。
